# AI-Based Cashflow Predictor

An AI-powered financial analytics and forecasting application built using Streamlit, Google Gemini AI, Pandas, and Plotly.

The system analyzes historical cashflow transactions, predicts future financial activity, answers business-related financial questions, and automatically generates data visualizations for better financial decision-making.

---

## Features

- Upload Excel or CSV cashflow data
- AI-based future cashflow prediction
- Interactive financial chatbot
- Smart financial insights using Gemini AI
- Automatic chart recommendations
- Dynamic chart generation using Plotly
- Download predicted cashflow data as CSV
- Financial trend analysis and visualization
- Session-based chatbot history tracking

---

## Tech Stack

- Python
- Streamlit
- Google Gemini AI
- Pandas
- Plotly
- JSON
- Regex

---

## Project Workflow

1. User uploads historical cashflow data
2. Data is cleaned and processed
3. Gemini AI analyzes transaction patterns
4. Future cashflows are predicted
5. Users can:
   - Download predictions
   - Ask financial questions
   - Generate analytical charts
6. AI suggests suitable chart types for visualization
